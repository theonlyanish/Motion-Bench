Duotone Gradient

Mix-blend-mode overlay

HTML · CSS · No dependencies · MIT

<div class="duotone-hover">
  <img src="https://picsum.photos/id/96/800/600" alt="Tools">

CSS

.duotone-hover {
  width: 400px;
  aspect-ratio: 4 / 3;
  overflow: hidden;
  border-radius: 12px;
  /* The tint color that shows through luminosity blending */
  background: #f00;
}

.duotone-hover img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
  mix-blend-mode: luminosity;
  filter: contrast(1.2);
  transition: mix-blend-mode 0.4s, filter 0.4s;
}

.duotone-hover:hover img {
  mix-blend-mode: normal;
  filter: none;
}
